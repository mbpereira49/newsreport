Claude Code’s “auto mode” gets a prompt-injection stress test

Anthropic has made the protective mode the default. A prominent researcher says he found a way around it that works most of the time.

Anthropic is leaning hard on Claude Code’s auto mode as a defense for people using coding agents against prompt-injection attacks. Simon Willison highlights a new test from Johann Rehberger, a well-known prompt-injection researcher, who says he found an attack that works about 80% of the time. The maneuver, as described, tricks Claude Code into downloading and uncompressing a zip archive, then executing code that imports base64 — while missing that the import can execute a local struct.py file extracted from the archive. The excerpt notes that auto mode did directly prevent the agent in a few cases, so this is not framed as a total bypass. But it is a sharp reminder that “default protection” is not the same thing as a solved security boundary.

Why it matters: Coding agents are moving from demos into developer workflows. If their safety modes can be reliably nudged into running hostile local code, the hard part is no longer whether agents can act — it is whether anyone can trust the guardrails around those actions.
