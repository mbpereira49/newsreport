The web’s crawler tax is becoming a real infrastructure bill

Git.kernel.org is reportedly spending more CPU rendering pages for scrapers than serving legitimate users.

Simon Willison points to Konstantin Ryabitsev’s account of abusive crawlers hammering git.kernel.org, the official Git repository for the Linux kernel. The quoted bottom line is grimly comic: the site spends more CPU cycles rendering commits for scrapers than on all legitimate access, including git clones. Across five geographically distributed nodes, 14 CPU cores are said to be doing nothing but rendering Git commits as HTML. Willison connects the problem to Datasette, which serves many crawlable pages, and tags the issue with crawling, AI ethics and infrastructure. The phrase “background radiation” captures the new normal: not a single attack, but constant machine attention.

Why it matters: The AI-era web has an externality problem. Crawlers may look like traffic, but at scale they shift costs onto maintainers of public-interest infrastructure.

Sources: Simon Willison
