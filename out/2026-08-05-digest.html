LLM 0.32 turns the command line into a better window on reasoning models

Simon Willison calls the release the project’s most significant since launch, with visible reasoning traces, OpenAI Responses support, server-side tools, and redesigned SQLite logs.

LLM 0.32 is a substantial release for people using the CLI as their daily interface to language models. The headliner is visibility: when running reasoning models, LLM can now show reasoning traces to standard error, letting users watch what the model is “thinking” without contaminating standard output that might be piped into another tool. The release also adds server-side provider tools, new models, OpenAI Responses API features, and content-addressable SQLite logs meant to make saved interactions smarter and more robust. Willison also shipped a major update to the llm-anthropic plugin alongside it.

Why it matters: The interesting move is not just new model support; it’s treating AI workflows like Unix workflows, where observability and clean streams matter.
